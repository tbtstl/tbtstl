I wanted a self-directed Wikipedia for rabbit holes, with an agent that could edit and create articles as I used it.

A question generates an article. Following a missing link generates its target. An article-scoped agent answers questions, edits pages, adds media, and creates linked pages.

## Changelog

### July 18–24, 2026

- Private workspaces now include invitations, persistent article discussions, workspace chat, activity history, and unread indicators.
- Added credit packs and workspace controls for shared AI usage.
- Articles can now draw from imported webpages, PDFs, and YouTube videos, with source material retained for grounded generation.
- External agents can now work with a workspace through personal access tokens, a REST API, or an MCP connection.
- Navigation, dialogs, reading views, and mobile layouts received a consistent responsive redesign.
